Installation i-Telex-Teilnehmerserver

sudo apt-get install node.js
sudo apt install npm
sudo apt install git
sudo apt install sqlite3
sudo npm install -g pm2
git clone https://github.com/soruh/I-Telex-Teilnehmerserver/ TlnServer
cd TlnServer
npm install
cp -r config_template config
[settings editieren]
node tools/init_sqlite3.js
node tools/manage_servers.js add <host> <port> <version>
Zertifikate kopieren
pm2 install pm2-logrotate
npm start
pm2 startup
--> gezeigte Zeile mit sudo von privelegiertem user ausführen
pm2 save

test:
node src/binaryserver/main.js
