How to update the Software of an ethernet board in the i-telex system
=====================================================================

You need: A Windows XP or Windows 7 PC with an serial interface (RS232) or an USB-to-serial adapter and a null-modem-cable.

If you already updateted your ethernet board once go you'll only need to change the file main.hex in your update directory and start with step 7.

1. Download all the files where you found this manual to the windows pc to any directory. This directory is called the "update directory"

2. Check the number of the serial interface. If it is COM1: goto step 7. If not, continue.

3. If the number is greater than 4 you have to change it to COM1: to COM4:

4. If the serial interface is not COM1: locate the file "upload.bat" in the update directory. Rightclick the file and select "edit"

5. In the text editor change the "/C1" to for expample "/C2", if the serial interface is COM2:

6. Choose File - Save from the texteditor menu and close the texteditor.

7. Connect the null-modem-cable to the serial interface or the adapter and to the i-telex-board (which must be powered and active).

8. Start "upload" or "upload.bat" from the update directory. A window with black background should appear with a text "COM 1 at 38400 Baud: " and a 'propelling' dash.

9. Restart the ethernet board. Press the button if the ethernet board for less then half a second. 

9a. If the blue LED lights up, press and hold the button if the ethernet board for approximately one second. The blue LED should go off for a very short period and light up again and stay on.

9b. If the blue LED did not light up by pressing the button, switch off the power of the i-telex system and on again. 

10. The propelling dash should disappear and a the following text should be visible:
COM 1 at 38400 Baud: Connected
Bootloader V2.1
Target: xxxxx fboot.DEF
Buffer: 7680 Byte
Size available: xxxxxx Byte
Program main.hex: 00000 - yyyyy
The "yyyyy" will be updated every few seconds.

11. Be patient until the blue LED goes off. This should take two to five minutes.
COM 1 at 38400 Baud: Connected
Bootloader V2.1
Target: xxxxx fboot.DEF
Buffer: 7680 Byte
Size available: xxxxxx Byte
Program main.hex: 00000 - yyyyy successful
Verify main.hex: 00000 - yyyyy successful
CRC: o.k.
Elapsed time: 0.00 seconds

12. Finished!

If something goes wrong during the update repeat the steps 8 to 12. In most cases the 
button won't work, so try step 9b.
